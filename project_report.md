# Text Statistics Analyzer

## Project Overview
A Python-based console application that analyzes text files and provides useful statistics such as word count, character count, line count, and word search functionality.

## Features
- Load text files
- Count words
- Count characters
- Count lines
- Search specific words
- Generate analysis report

## Technologies Used
- Python 
- File Handling
- Object-Oriented Programming

## Project Structure

TextStatisticsAnalyzer.py - Main application

sample.txt - Sample input file

report.txt - Generated report

requirements.txt - Project dependencies
